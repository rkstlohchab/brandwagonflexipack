# Brandwagon Flexipack website

Static multi-page website for Brandwagon Flexipack Private Limited.

Pages:
- index.html
- products.html
- product.html?id=...
- about.html
- applications.html
- contact.html

The catalogue is based on the 20-product reference range visible on Keni Industries' current product page. Product imagery is linked to the existing external product-image sources rather than AI-generated artwork.

No contact form is included; contact is direct phone/email.

The website is static and can be deployed to Netlify, Vercel static hosting, GitHub Pages or any standard web server.
